# 中转站使用

本页概览从注册账号到创建 API Key、选择分组、查看用量的完整流程。完成后继续阅读 [接入使用](./integration.md)。

## 使用流程总览 {#overview}

1. 注册或登录账号。
2. 了解余额计费与订阅套餐。
3. 创建 API Key。
4. 为 API Key 选择分组。
5. 复制密钥并接入客户端。
6. 在站内查看用量与余额。

## 1. 创建账号 {#account}

打开瑞科 API 站点后，点击注册入口：

- 输入邮箱和密码。
- 如开启邮箱验证，填写 6 位验证码。
- 如开启邀请码注册，填写邀请码。
- 注册成功后进入仪表盘。

已有账号直接登录即可。第三方登录入口以页面实际展示为准。

## 2. 计费与订阅的区别 {#billing-subscription}

- **余额计费**：先充值余额，调用 API 时按实际消耗扣费。适合测试、临时使用、按需使用。
- **订阅套餐**：购买某个分组对应的套餐，在有效期内按套餐规则使用。适合固定模型或高频使用。
- **分组**：决定 API Key 走哪类上游能力，例如 Claude、OpenAI、Gemini、Antigravity。

价格、倍率、有效期、额度和套餐权益以站内显示为准。

## 3. 创建 API Key {#api-key}

进入“API 密钥”页面：

1. 点击“创建密钥”。
2. 填写名称。
3. 选择分组。
4. 按需设置额度、速率、有效期或 IP 限制。
5. 保存后复制 API Key。

第一次使用时，通常只需要填写名称并选择分组。

## 4. 选择分组 {#group}

按你要接入的客户端选择分组：

- Claude Code：选择 Claude / Anthropic 类分组。
- Codex CLI：选择 OpenAI 类分组。
- Gemini CLI：选择 Gemini 类分组。
- Antigravity：按实际客户端选择 Claude Code 或 Gemini CLI。

如果 API Key 没有分组，“使用密钥”和“导入到 CCS”可能无法生成正确配置。

## 5. 查看用量 {#usage}

常用入口：

- **仪表盘**：查看余额、请求数、Token 和分组使用概览。
- **使用记录**：查看每次请求的模型、费用、耗时和 Token。
- **API Key 用量查询**：快速确认密钥状态、余额、订阅和额度。
- **CC Switch**：导入 Provider 后可通过 `/v1/usage` 查看余额或额度。
